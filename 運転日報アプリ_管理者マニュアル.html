📁 第1章　初回セットアップ（最初の一回だけ）
💡 この章でやること
Googleスプレッドシートの作成とGASの設定を行います。一度設定すれば、以降は触らなくてよいです。
1-1　Googleスプレッドシートを作る
1
会社の共有GoogleアカウントでChromeにログインする
個人アカウントではなく会社の共有アカウントを使用してください。
2
スプレッドシートを新規作成する
sheets.google.com を開き、「＋ 新しいスプレッドシート」をクリックしてください。
3
シート名を「運転日報」に変える
画面左下の「Sheet1」タブを右クリック →「名前を変更」→「運転日報」と入力してEnterを押してください。
4
1行目にヘッダーを入力する
A1セルから以下をコピー＆ペーストしてください（自動的に11列に入ります）：
日付 担当者 車両番号 対象年月 運転者 同乗者 走行距離(km) メーター指針 給油量(L) アルコール確認 備考
💡 車両タブについて
メンバーがデータを送信すると、車両番号ごとのタブが自動的に作成されます。管理者が手動でタブを作る必要はありません。
1-2　Google Apps Script（GAS）を設定する
1
Apps Scriptを開く
スプレッドシートのメニューから「拡張機能」→「Apps Script」をクリックしてください。
2
既存のコードを全部消す
Ctrl+A（全選択）→ Delete で消してください。
3
以下のコードを貼り付ける
「ここにキーを入れる」の部分だけ自分で決めた合言葉に変えてください。

'なし' : data.alco === 'ari' ? 'あり' : data.alco; const row = [data.date, data.tanto, data.car, data.month, data.driver, data.passenger, data.km, data.meter, data.fuel, alco, data.notes]; let updated = false; for (let i = 1; i < rows.length; i++) { if (formatDate(rows[i][0]) === dateStr && String(rows[i][1]).trim() === tantoStr) { sheet.getRange(i+1, 1, 1, 11).setValues([row]); updated = true; break; } } if (!updated) sheet.appendRow(row); const lastRow = sheet.getLastRow(); if (lastRow > 2) { sheet.getRange(2, 1, lastRow - 1, 11).sort([ { column: 1, ascending: true }, { column: 2, ascending: true } ]); } return ContentService.createTextOutput(JSON.stringify({status: updated ? 'updated' : 'ok'})).setMimeType(ContentService.MimeType.JSON); } catch(err) { return ContentService.createTextOutput(JSON.stringify({error:err.message})).setMimeType(ContentService.MimeType.JSON); } } function doGet(e) { if (e.parameter.accessKey !== ACCESS_KEY) { return ContentService.createTextOutput(JSON.stringify({error:'unauthorized'})).setMimeType(ContentService.MimeType.JSON); } const ss = SpreadsheetApp.getActiveSpreadsheet(); const month = e.parameter.month; const car = e.parameter.car; const data = []; const sheets = car ? [ss.getSheetByName(car)] : ss.getSheets(); sheets.forEach(sheet => { if (!sheet) return; const rows = sheet.getDataRange().getValues(); for (let i = 1; i < rows.length; i++) { if (!month || String(rows[i][3]) === month) { data.push({date:formatDate(rows[i][0]), tanto:rows[i][1], car:rows[i][2], month:rows[i][3], driver:rows[i][4], passenger:rows[i][5], km:rows[i][6], meter:rows[i][7], fuel:rows[i][8], alco:rows[i][9], notes:rows[i][10]}); } } }); return ContentService.createTextOutput(JSON.stringify({data})).setMimeType(ContentService.MimeType.JSON); }

📅 第3章　毎月の作業（月初にやること）
💡 対象年月の切り替えは自動です
月が変わると、各メンバーがアプリを開いたときに「対象年月を変更しますか？」と自動で表示されます。管理者からの月初連絡は必須ではありませんが、切り替え忘れ防止のため念のため声かけすると確実です。
  • スプレッドシートを開き、前月のデータが各車両タブに揃っているか確認する
  • データに漏れがある場合は該当メンバーに個別連絡する
  • 必要であればスプレッドシートを印刷・PDF出力する
  • （推奨）Chatworkで「月が変わったのでアプリの切り替え確認でOKを押してください」と一声かける
メンバーへ送るメッセージ例（月初・任意）
【運転日報　月次切替のお知らせ】 お疲れ様です。 月が変わりましたので、運転日報アプリを開いて 「対象年月を変更しますか？」の確認が出たら「OK」を押してください。 ※前月分の入力が残っている方は「キャンセル」して 　入力を済ませてから切り替えてください。 ご不明な点は管理者までご連絡ください。
👤 第4章　メンバーが増えた・変わったとき
新しいメンバーが加わったとき
1
ChatworkでアプリURLと使い方ガイドURLを送る
第2章のメッセージ例をそのまま使えます。
2
GAS URLをChatworkで個別に送る
既存メンバーと同じURLで問題ありません。
3
アクセスキーを口頭で伝える
既存メンバーと同じキーです。Chatworkでは送らないでください。
メンバーが退職・担当変更したとき
⚠️ アクセスキーの変更について
退職者がいる場合、アクセスキーの変更を推奨します。GASのコードの ACCESS_KEY を書き換えて再デプロイし、全メンバーに新しいキーを口頭で伝えてください。
GASのアクセスキーを変更する手順
1
スプレッドシートを開き「拡張機能」→「Apps Script」
2
コード1行目のキーを新しい文字列に変える
const ACCESS_KEY = '新しいキー'; // ← ここを変更
3
保存して再デプロイする
「デプロイ」→「デプロイを管理」→ 鉛筆アイコン →「新しいバージョン」→「デプロイ」
4
全メンバーに新しいキーを口頭で伝える
各自がアプリの設定タブでキーを更新する必要があります。
🆘 第5章　トラブル対応
❓ メンバーから「送信できない」と連絡が来た
確認順序：
① アクセスキーが正しいか（設定タブで確認してもらう）
② GAS URLが正しいか（設定タブで確認してもらう）
③ インターネットに繋がっているか
④ 上記でも解決しなければGASの再デプロイを試みる
❓ スプレッドシートにデータが届かない
① メンバーのアプリで「✓ 保存してスプレッドシートに送信」ボタンを押しているか確認
② ⚠️マークが残っている場合は送信失敗。再度ボタンを押してもらう
③ GASのデプロイが「アクセスできるユーザー：全員」になっているか確認
❓ GASのURLを忘れてしまった
スプレッドシートを開き「拡張機能」→「Apps Script」→「デプロイ」→「デプロイを管理」を開くと現在のURLが確認できます。
❓ Googleアカウントが使えなくなった
Googleアカウントの復旧手順に従って対応してください。復旧できない場合は新しいアカウントで第1章からやり直す必要があります。スプレッドシートのURLとアクセスキーは必ず別の場所に控えておいてください。
❓ メンバーから「警告メッセージが出た」と質問が来た
アプリには以下の自動チェックがあり、いずれも正常な動作です：
①「対象年月を変更しますか？」…月が変わったときの切り替え確認
②「未送信のデータが◯件あります」…送信忘れのお知らせ（該当日を再送信すれば消える）
③「前日のメーター指針より小さい値です」…入力ミスの可能性の警告
④「アルコール確認が未選択です」…選択忘れの確認
❓ アプリの中身を変更したい・機能を追加したい
アプリはGitHub（https://github.com/takatodec02-commits/driving-log）で管理しています。変更にはある程度の知識が必要なため、元の開発担当者か専門の人に依頼することを推奨します。
✅ 定期バックアップのすすめ
月に一度、スプレッドシートを「ファイル」→「ダウンロード」→「Microsoft Excel形式」でダウンロードしてPCに保存しておくと安心です。
