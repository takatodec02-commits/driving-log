📁 第1章　初回セットアップ（最初の一回だけ）
💡 この章でやること
Googleスプレッドシートの作成とGASの設定を行います。一度設定すれば、以降は触らなくてよいです。
1-1　Googleスプレッドシートを作る
1
Googleにログインする
会社のGoogleアカウントでログインしてください。個人アカウントでも可ですが、会社のものが推奨です。
2
スプレッドシートを新規作成する
ブラウザで sheets.google.com を開き、「＋ 新しいスプレッドシート」をクリックしてください。
3
シート名を「運転日報」に変える
画面左下の「Sheet1」タブを右クリック →「名前を変更」→「運転日報」と入力してEnterを押してください。
4
1行目にヘッダーを入力する
A1セルから順番に以下の11項目を入力してください（コピー＆ペーストでOK）：
日付 担当者 車両番号 対象年月 運転者 同乗者 走行距離(km) メーター指針 給油量(L) アルコール確認 備考
※タブ区切りになっています。そのままコピーしてA1セルに貼り付けると11列に自動で入ります。
1-2　Google Apps Script（GAS）を設定する
💡 GASとは？
Googleが提供する無料のプログラム機能です。アプリからのデータを受け取ってスプレッドシートに書き込む「橋渡し役」です。難しいことは不要で、コードをコピー＆ペーストするだけです。
1
Apps Scriptを開く
スプレッドシートの上のメニューから「拡張機能」→「Apps Script」をクリックしてください。
2
既存のコードを全部消す
エディタに最初から入っているコードを Ctrl+A（全選択）→ Delete で消してください。
3
以下のコードを貼り付ける
下のコードを全部コピーして貼り付けてください。
「ここにキーを入れる」の部分だけ自分で決めた合言葉に変えてください。
const SHEET_NAME = '運転日報'; const ACCESS_KEY = 'ここにキーを入れる'; // ← 自分で決めた合言葉に変える function doPost(e) { try { const data = JSON.parse(e.postData.contents); if (data.accessKey !== ACCESS_KEY) { return ContentService.createTextOutput( JSON.stringify({error:'unauthorized'}) ).setMimeType(ContentService.MimeType.JSON); } const ss = SpreadsheetApp.getActiveSpreadsheet(); const sheet = ss.getSheetByName(SHEET_NAME); const rows = sheet.getDataRange().getValues(); const alco = data.alco === 'nashi' ? 'なし' : data.alco === 'ari' ? 'あり' : data.alco; const row = [ data.date, data.tanto, data.car, data.month, data.driver, data.passenger, data.km, data.meter, data.fuel, alco, data.notes ]; for (let i = 1; i < rows.length; i++) { if (rows[i][0]===data.date && rows[i][1]===data.tanto && rows[i][2]===data.car) { sheet.getRange(i+1,1,1,11).setValues([row]); return ContentService.createTextOutput( JSON.stringify({status:'updated'}) ).setMimeType(ContentService.MimeType.JSON); } } sheet.appendRow(row); return ContentService.createTextOutput( JSON.stringify({status:'ok'}) ).setMimeType(ContentService.MimeType.JSON); } catch(err) { return ContentService.createTextOutput( JSON.stringify({error:err.message}) ).setMimeType(ContentService.MimeType.JSON); } } function doGet(e) { if (e.parameter.accessKey !== ACCESS_KEY) { return ContentService.createTextOutput( JSON.stringify({error:'unauthorized'}) ).setMimeType(ContentService.MimeType.JSON); } const ss = SpreadsheetApp.getActiveSpreadsheet(); const sheet = ss.getSheetByName(SHEET_NAME); const rows = sheet.getDataRange().getValues(); const month = e.parameter.month; const data = []; for (let i = 1; i < rows.length; i++) { if (!month || String(rows[i][3]) === month) { data.push({ date:rows[i][0], tanto:rows[i][1], car:rows[i][2], month:rows[i][3], driver:rows[i][4], passenger:rows[i][5], km:rows[i][6], meter:rows[i][7], fuel:rows[i][8], alco:rows[i][9], notes:rows[i][10] }); } } return ContentService.createTextOutput( JSON.stringify({data}) ).setMimeType(ContentService.MimeType.JSON); }
4
保存する
画面上の💾（フロッピーアイコン）をクリック、またはCtrl+Sを押してください。
5
デプロイ（公開）する
① 右上の「デプロイ」ボタン →「新しいデプロイ」をクリック
② 左の歯車アイコン →「ウェブアプリ」を選択
③ 設定を以下のようにする：
　・次のユーザーとして実行：自分
　・アクセスできるユーザー：全員
④「デプロイ」をクリック
⑤ Googleアカウントの許可を求められたら「詳細」→「〜に移動（安全ではないページ）」→「許可」をクリック
6
ウェブアプリのURLをメモする
「デプロイが完了しました」画面に表示される 「ウェブアプリのURL」 をコピーしてどこかに保存しておいてください。このURLはメンバーに配布するアプリの設定に必要です。
⚠️ アクセスキーについて
コードの中の ACCESS_KEY に入れた文字列がアクセスキーです。メンバーへの共有は口頭か電話で行ってください。ChatworkやメールなどURLと同じ経路では送らないでください。

📅 第3章　毎月の作業（月初にやること）
  • Chatworkで全メンバーに「対象年月を〇〇年〇〇月に変更してください」と連絡する
  • スプレッドシートを開き、前月のデータがすべて揃っているか確認する
  • データに漏れがある場合は該当メンバーに個別連絡する
  • 必要であれば集計タブから月次レポートを印刷・PDF出力する
メンバーへ送るメッセージ例（月初）
【運転日報　月次切替のお知らせ】 お疲れ様です。 運転日報アプリの対象年月を変更してください。 【変更手順】 ① アプリを開く ② 「⚙️ 設定」タブをタップ ③「対象年月」を「2026-07」に変更 ④「💾 設定を保存」をタップ ご不明な点は澤田までご連絡ください。
💡 スプレッドシートの確認方法
スプレッドシートを開いて「日付」列を確認し、先月の日付でデータが8名分届いているかチェックしてください。担当者名でフィルターをかけると確認しやすいです。
👤 第4章　メンバーが増えた・変わったとき
新しいメンバーが加わったとき
1
Chatworkで2つのファイルを送る
driving log shared.html と 使い方ガイド.html を送る
2
GAS URLをChatworkで送る
既存メンバーと同じURLで問題ありません
3
アクセスキーを口頭で伝える
既存メンバーと同じキーです。Chatworkでは送らないでください
メンバーが退職・担当変更したとき
⚠️ アクセスキーの変更について
退職者がいる場合、アクセスキーを変更することを推奨します。変更する場合はGASのコードの ACCESS_KEY を書き換えて再デプロイし、全メンバーに新しいキーを口頭で伝えてください。
GASのアクセスキーを変更する手順
1
スプレッドシートを開き「拡張機能」→「Apps Script」
2
コードの2行目のキーを新しい文字列に変える
const ACCESS_KEY = '新しいキー'; // ← ここを変更
3
保存して再デプロイする
「デプロイ」→「デプロイを管理」→ 鉛筆アイコン →「新しいバージョン」→「デプロイ」
4
全メンバーに新しいキーを口頭で伝える
各自がアプリの設定タブでキーを更新する必要があります
🆘 第5章　トラブル対応
❓ メンバーから「送信できない」と連絡が来た
確認順序：
① アクセスキーが正しいか（設定タブで確認してもらう）
② GAS URLが正しいか（設定タブで確認してもらう）
③ インターネットに繋がっているか
④ 上記でも解決しなければGASの再デプロイを試みる
❓ スプレッドシートにデータが届かない
① メンバーのアプリで「✓ 保存してスプレッドシートに送信」ボタンを押しているか確認
② ⚠️マークが残っている場合は送信失敗。再度ボタンを押してもらう
③ GASのデプロイが「アクセスできるユーザー：全員」になっているか確認
❓ GASのURLを忘れてしまった
スプレッドシートを開き「拡張機能」→「Apps Script」→「デプロイ」→「デプロイを管理」を開くと現在のURLが確認できます
❓ Googleアカウントのパスワードを忘れた・アカウントが使えなくなった
Googleアカウントの復旧手順に従って対応してください。復旧できない場合は新しいアカウントで第1章からやり直す必要があります。スプレッドシートのURLとアクセスキーは必ず別の場所に控えておいてください。
❓ アプリの中身を変更したい・機能を追加したい
アプリ（driving log shared.html）はテキスト形式のファイルです。変更にはある程度の知識が必要なため、元の開発担当者か専門の人に依頼することを推奨します。
✅ 定期バックアップのすすめ
月に一度、スプレッドシートを「ファイル」→「ダウンロード」→「Microsoft Excel形式」でダウンロードしてPCに保存しておくと安心です。
